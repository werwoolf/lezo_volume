# VolumeControl — повна заміна штатного регулятора звуку

Menu bar застосунок, який повертає керування гучністю, коли ти слухаєш через
об'єднаний (Multi-Output / Aggregate) пристрій — ситуацію, де macOS блокує
штатний регулятор.

## Що вміє

- **Фізичні клавіші гучності** працюють як завжди: **F12** +10, **F11** −10,
  **F10** вимкнути/ввімкнути звук. Застосовується до всіх виходів об'єднаного
  пристрою.
- Показує рівень (%) з іконкою в рядку меню + повзунок у меню.
- **Вибір пристрою виводу** прямо в меню (список з галочкою на поточному) — як у
  штатному меню «Звук».
- Пункт **«Налаштування звуку…»** відкриває системні налаштування звуку.
- OSD-оверлей (напівпрозорий HUD) при кожній зміні.
- Резервні горячі клавіші **⌃⌥↑ / ⌃⌥↓** — працюють навіть без дозволу Accessibility.

## Збірка

Потрібні Xcode Command Line Tools (якщо немає — `xcode-select --install`).

```bash
cd /шлях/до/папки
chmod +x build.sh
./build.sh
open VolumeControl.app
```

## Дозвіл Accessibility (для фізичних клавіш)

Перехоплення клавіш F10/F11/F12 потребує одноразового дозволу:

1. При першому запуску з'явиться системний запит — натисни **Open System Settings**.
2. **System Settings → Privacy & Security → Accessibility** → увімкни перемикач
   біля **VolumeControl**.
3. Якщо клавіші не запрацювали одразу — **перезапусти застосунок** (вийти через
   меню → `open VolumeControl.app`). Без дозволу повзунок і ⌃⌥↑/↓ все одно працюють.

У меню є пункт **«⚠︎ Дозволити клавіші гучності…»** — він з'являється, лише поки
дозволу немає, і веде прямо в потрібний розділ налаштувань.

## Прибрати дубль іконки звуку

Щоб лишився тільки наш індикатор:

**System Settings → Control Center → Sound (Звук) → «Don't Show in Menu Bar»**

Вибір пристрою виводу й налаштування звуку тепер є в меню нашого застосунку, тому
штатна іконка не потрібна.

## Автозапуск при вході

**System Settings → General → Login Items → Open at Login → +** і додай
`VolumeControl.app`. (Раджу спершу перемістити `.app` у `~/Applications`, щоб шлях
не змінювався.)

## Налаштування (у VolumeControl.swift)

- `private let step = 10` — крок зміни у відсотках.
- `kSoundUp / kSoundDown / kMute` — коди клавіш (стандартні NX_KEYTYPE_*).
- Резервні Carbon-клавіші — у `setupHotKeys()` (`kVK_UpArrow`/`kVK_DownArrow`,
  модифікатори `controlKey | optionKey`).

Після правок перезбери: `./build.sh`.

## Можливі проблеми компіляції

- **`kAudioObjectPropertyElementMain` не знайдено** — стара macOS (<12). Заміни всі
  входження на `kAudioObjectPropertyElementMaster`.
- **`paletteColors` / `applying` недоступні** — дуже стара система; прибери в
  `OSDView.draw` рядок із `.applying(...)`.
- Перший запуск неписаного застосунку: правий клік по `.app` → **Open** → **Open**.

## Чому так, а не штатним регулятором

macOS навмисно вимикає системний регулятор гучності для Multi-Output/Aggregate
пристроїв: він «прозорий», і система не знає, якому саме субпристрою слати зміну.
Застосунок обходить це, звертаючись до кожного субпристрою напряму через CoreAudio
(`kAudioDevicePropertyVolumeScalar`), а клавіші гучності перехоплює через CGEventTap.
